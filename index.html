System and method for bidirectional memory R/W via closed-loop processing

Abstract. A brain–computer interface system for reading and writing human memory comprising: (a) a multi-site hippocampal neural recording array; (b) a real-time signal processing pipeline extracting oscillatory band features with latency < 2 ms; (c) a per-subject latent dynamical system decoder associating population activity with sparse memory index codes; (d) a closed-loop stimulation subsystem delivering site-specific microstimulation within 18 ms of event detection; and (e) a manifold-constrained pattern synthesizer projecting target memory content onto the subject's intrinsic neural manifold prior to injection.

The system operates across four memory phases — encoding, consolidation, retrieval, and de novo write — under a unified 1,024-dimensional sparse hippocampal index. Novelties include: content-selective sharp-wave ripple (SWR) boosting during NREM sleep; manifold-constrained engram synthesis using seed-plus-autoassociative-completion injection; inhibitory co-sculpting via interneuron subtype coordination; and a bidirectional read-back fidelity verification loop with reject-on-drift scheduling.

01FIELD & BACKGROUND

Technical field and prior art limitations.

The system relates to brain–computer interfaces for hippocampal-dependent episodic memory. Prior systems address at most one phase of the memory lifecycle and share critical architectural gaps that this disclosure resolves.

Technical Field. The present system falls within the fields of neurotechnology, computational neuroscience, and neuroprosthetics, specifically addressing closed-loop neural interfaces for bidirectional manipulation of hippocampal-dependent episodic and procedural memory in human subjects.

Episodic memory is encoded via synaptic plasticity across hippocampal subfields CA3, CA1, and dentate gyrus (DG), stabilized by sharp-wave ripple (SWR)-driven replay during NREM sleep, and retrieved via a pattern-completion attractor dynamic in CA3. The hippocampus acts as a sparse pointer into distributed cortical memory traces rather than storing the traces themselves (Teyler & DiScenna 1986; Squire et al. 2004). This architectural insight — that intervention on the pointer is orders of magnitude more tractable than intervention on the full cortical trace — is the foundational principle of the present system.

Problem Statement. Pathological memory disruption affects an estimated 50 million individuals worldwide (Alzheimer's disease, PTSD, traumatic brain injury, treatment-resistant depression). Current pharmacological interventions lack precision; deep brain stimulation systems are open-loop and non-specific. No existing system supports the full memory lifecycle — encoding, consolidation, retrieval, and writing — in a single integrated architecture.

Background. Closed-loop neural recording and stimulation technology has advanced significantly: Neuropixels arrays now record >10,000 neurons simultaneously with single-cell resolution; on-chip neuromorphic ASICs can run low-latency spike sorting; and novel algorithms (LFADS, GPFA) extract low-dimensional latent dynamics from high-dimensional population recordings. The missing component is a unified system architecture that coordinates these capabilities across the four phases of memory formation on their natural timescales — from millisecond spike bursts to multi-night consolidation.

Gap Analysis. Prior systems (see table below) each address one or two isolated phases. None addresses content-selective SWR boosting, manifold-constrained write, or the bidirectional shared index. The unresolved challenge is that any engram pattern injected into hippocampus that lies off the subject's intrinsic neural manifold will be rejected by recurrent network dynamics within one theta cycle (~130 ms), rendering the write ineffective (Sadtler et al. 2014). The present system resolves this with a per-subject manifold calibration and constrained projection pipeline.

02SYSTEM ARCHITECTURE

Four-phase closed loop across the memory lifecycle.

The system unifies encoding, consolidation, retrieval, and write under a single sparse hippocampal index. Each phase exposes read (decode) and write (stim) primitives at its native timescale. The shared index guarantees that written memories are accessible by the same retrieval machinery that reads natural ones.

03DETAILED DESCRIPTION

Subsystem specifications.

A detailed description of the preferred embodiment of each subsystem, including signal processing parameters, algorithmic architecture, stimulation protocols, and critical design constraints.

SUBSYSTEM 1A · ENCODER PHASE

Prediction-Error Monitor

Algorithm
Hierarchical predictive coding; difference between cortical expectation model output and observed LFP/spike patterns across layers II–V.
PE threshold
Z ≥ 2.0σ above 5-min rolling baseline; computed per cortical area (PFC, ACC, temporal cortex) independently.
Gate criterion
Joint PE × PAC: both must exceed threshold within the same 500 ms window for encoding-worthy flag.
Update rate
500 Hz; 200 ms overlapping sliding window; running Z-score on decoded PE magnitude.
Output
Binary encoding flag + continuous novelty score [0, 1] + timestamp for STC scheduler.
Motivated by Lisman & Grace (2005) hippocampal–VTA loop: novelty-triggered DA release gates plasticity. The monitor provides an artificial surrogate trigger.
SUBSYSTEM 1B · ENCODER PHASE

θ–γ Phase-Amplitude Coupling Tracker

Method
Hilbert transform on 4–8 Hz (θ) and 30–100 Hz (γ) filtered LFPs from 16 CA1 electrodes. Modulation Index per Tort et al. (2010): 18 θ-phase bins, KL-divergence from uniform.
Active-encoding flag
MI > 0.25 sustained for ≥ 200 ms; computed per 100 ms overlapping window (10 Hz update rate).
Phase reference
θ trough (minimum LFP) = preferred phase for gamma coupling and encoding (Lisman & Jensen 2013).
Multi-item gating
PAC phase-position encodes up to 7 items per θ cycle (Working Memory); each γ burst = one item slot.
PAC index is the most reliable predictor of successful encoding in human iEEG (Axmacher et al. 2010, J. Neurosci.). System treats MI as a real-time encoding-quality signal.
SUBSYSTEM 2A–2B · CONSOLIDATION PHASE

SWR Detector + Content Classifier

Detection filter
4th-order Butterworth, 150–250 Hz; IIR implementation, 0.3 ms group delay. RMS power > 4σ above 30 s baseline, sustained ≥ 25 ms.
Exclusion criteria
Coincident EMG artifact (differential electrode), active θ epoch (SWRs excluded during wakeful locomotion), artifact-free < 95% of 250 ms window.
Detector latency
8 ms from SWR onset to detection flag (measured vs. offline oracle: 94% sensitivity, 6% FPR).
Classifier architecture
LFADS (Latent Factor Analysis via Dynamical Systems): 64-dim latent space from 4,096-channel spike rates, 10 ms bins, INT8 quantized.
Memory ID lookup
Cosine similarity to stored library of per-subject memory templates. Threshold: r > 0.65 for classification. Library size: up to 10,000 events.
Inference latency
12 ms on neuromorphic ASIC; 80 ms on edge GPU (Tier 2).
Content-selectivity is the key novelty over prior SWR-boosting systems (Girardeau et al. 2009; Ego-Stengel & Wilson 2010), which stimulate all detected SWRs indiscriminately.
SUBSYSTEM 2C · CONSOLIDATION PHASE

SO–Spindle Phase Lock Controller

SO detection
0.5–1 Hz bandpass; peak-to-trough amplitude > 75 µV (surface EEG) or > 250 µV (depth electrode). Must precede intervention.
Spindle detection
12–15 Hz; Morlet wavelet (σ = 7 cycles); power Z > 3 above background. Concurrent with SO up-state required.
Intervention window
100–400 ms post-SO trough (up-state). Stim or cue must land within this window to couple to spindle → SWR cascade.
Stage confirmation
N3 confirmed by EEG staging (SleepSEEG algorithm, Iber et al. 2007 criteria) for ≥ 30 s prior to intervention epoch.
Safety: rest window
Minimum 4 min of uninterrupted sleep between consecutive intervention epochs.
The SO–spindle–ripple temporal sequence is the canonical consolidation mechanism (Staresina et al. 2015, Nature Neurosci.). Interventions that miss the up-state window fail to couple to the cascade.
SUBSYSTEM 4B · WRITE PHASE

Manifold-Constrained Encoder

Manifold learning
Gaussian Process Factor Analysis (GPFA) on trial-averaged population activity from ≥ 10 calibration sessions, ≥ 200 trials each. Intrinsic dimensionality: 8–12 dims capture > 85% of total variance.
Content embedding
Target content (text/visual/motor) mapped to neural-semantic space via per-subject encoder trained on naturalistic stimuli with concurrent neural recording.
Manifold snap
Gradient descent to nearest on-manifold point in 8–12 dim subspace. Convergence criterion: residual off-manifold component < 0.05. Abort write if residual ≥ 0.05.
Compute time
120 ms GPFA embedding + 65 ms gradient snap = 185 ms total (A100 GPU, batch size 1).
Recalibration
Manifold updated after every 20-session block; drift detection triggers early recalibration if explained variance drops > 5%.
Directly addresses Sadtler et al. (2014) off-manifold failure mode. Any pattern not within the subject's intrinsic manifold is rejected by CA3 recurrent dynamics within one θ cycle (≈ 130 ms).
SUBSYSTEM 4C–4D · WRITE PHASE

Seed Injection + Inhibitory Co-Sculpting

Seed fraction
20–30% of target engram sites (289/1024 in preferred embodiment). Below 20% → CA3 attractor fails to converge. Above 35% → over-determination, no autoassociative completion.
Injection protocol
Multi-site biphasic current, 44 µA, 180 µs/phase. Delivered at θ trough (minimum excitability) via θ-phase predictor (4.8 ms compute). Wait: up to 130 ms (one θ cycle at 7.7 Hz).
VIP+ disinhibition
20 Hz burst, 5 pulses, 15 µA, co-delivered 20 ms before seed. Opens disinhibitory gate: VIP→SST/PV suppression removes lateral inhibition that would otherwise reject novel patterns.
SST+ lateral cap
Simultaneous 40 Hz stim at 6 surrounding sites, 10 µA. Prevents runaway excitation and engram spread beyond target sites (size control).
PV+ offset burst
200 Hz, 3-pulse burst at injection offset. Sharp inhibition clocks the engram window, enforces temporal precision, and resets network for next θ cycle.
Convergence check
CA3 population activity monitored for attractor convergence: Hamming distance to target < 0.02 within 7 iterations (~70 ms).
First protocol to engineer the inhibitory landscape alongside excitation. Inhibitory co-sculpting is mechanistically distinct from all prior optogenetic engram studies (Roy et al. 2016, Liu et al. 2012) which only manipulate excitatory cells.
04CORE REPRESENTATION

The sparse index.

The system does not attempt to read or write full cortical memory traces — an impossibility at current electrode densities. Instead it would attempt to operate on the hippocampal index: a 1,024-dimensional sparse pointer (k=48 active bits) whose reactivation reinstates the distributed cortical pattern. This reduces decoder complexity by three to four orders of magnitude.
